# Firm workspace editing ownership

Cornerstone supports the firm's lead-to-matter, drafting, billing, and client-portal work. The daily navigation links directly to Leads and the Matters list; the CRM subpages remain available.

| Information | Authoritative editor |
| --- | --- |
| Intake facts | Intake editor |
| Plan design and legal drafting decisions | Existing design-sheet workspace |
| Matter identity, stage and status | Matter controls |
| Charges, invoices, payments and adjustments | Billing |
| Secure client correspondence | Portal messages on the matter |
| Phone and text communications | External communications service |
| Marketing consent/opt-out | Existing consent record; historical values retained |

Summary views should link to these editors. They must not introduce another design-sheet store or imply that legal drafting work can be completed automatically. Stripe is the implemented online payment processor; LawPay is unsupported. The trust-funding narrative prompt moved to the document-generation proposal notes and is not active runtime behavior.

Remaining planned changes include practice-specific portal milestones, a slimmer matter overview, and globally paginated working lists. They are not implied by the navigation-label changes in this release.
